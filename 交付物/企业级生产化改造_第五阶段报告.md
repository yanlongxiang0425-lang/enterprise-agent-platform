# 企业级生产化改造_第五阶段报告

检查时间：2026-05-18

## 1. 阶段结论

第五阶段完成“纯平台命名 + 企业级底座入口补齐”。

旧的 `/api/material-agent/...` HTTP 接口和 `material-agent` 脚本入口已移除。当前对外统一使用 `enterprise-agent-platform` 项目命名、`agent-platform` CLI 和 `/api/agent-platform/...` API 前缀。内部 `material_agent` 包暂保留为物料分类业务实现模块，避免无收益的大规模迁移；对外接口已经是平台级命名。

本阶段新增 Tool/MCP/Skill 能力入口、Model Gateway 路由入口、知识库导入/进度/导出/下载路径骨架，并保持原有物料分类样例验证正常。

## 8. 当前仍可继续改造点

下一阶段建议继续做“平台能力从本地骨架走向生产实现”：

1. 将 Tool/MCP/Skill、Model Gateway、Knowledge Base 注册信息迁移到数据库。
2. 增加真实文件上传接口，当前本地骨架是通过 `source_file` 路径导入。
3. 知识库从 manifest 升级为分片、Embedding、向量索引和结构化索引。
4. 增加导入进度事件：uploaded/parsed/chunked/embedded/indexed/completed。
5. 增加文件下载授权、临时下载 URL 或对象存储签名 URL。
6. 增加 AgentHandler 协议，把物料分类处理逻辑从通用任务服务中拆成可插拔 handler。
7. 增加平台级鉴权、租户、审计、限流和 OpenTelemetry。

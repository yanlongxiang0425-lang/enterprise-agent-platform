## 1. 阶段结论

本阶段已把物料分类补全 Agent 从“样例可运行工程骨架”推进到“企业生产级工程骨架第一阶段”。

## 5. 下一阶段建议

第二阶段建议聚焦“任务化与持久化”：

1. 增加任务模型：`task_id`、状态、输入文件、输出文件、错误信息、创建人、时间戳。
2. 增加本地/数据库任务仓储接口，先实现文件仓储，后续替换 PostgreSQL。
3. API 改成 `create task -> run worker -> query status -> download result`。
4. 增加任务级审计日志和文件指纹。
5. 将当前同步 CLI 保留为本地验证入口。

第三阶段再推进 LangGraph checkpoint、人工确认节点、Redis 队列、PostgreSQL/pgvector、OpenTelemetry、鉴权和脱敏。
